# 业务 Memory TTL 受控回放实验

- 语料：100 份简历，15 个岗位 cohort
- 时间：365 天受控 Poisson 到达流，稀疏/正常/繁忙三档
- 候选人识别：不需要；案例按岗位隔离且脱敏
- 线上数据变更：无

## 决策

- `RECENT_CASE`: **30 天**
- `JOB_PROFILE`: **180 天**
