# Job-relevance checklist

For every score, risk, and recommendation reason, answer all items:

1. Which explicit JD requirement does this measure?
2. Which candidate source reference supports the observation?
3. Is the criterion applied consistently to every candidate for this role?
4. Does the reason rely on a protected attribute or a proxy such as graduation year, school prestige, employer prestige, address, employment gap, or job-change count?
5. Does the wording distinguish evidence absence from ability absence?
6. Would removing identifying fields change the conclusion? If yes, require human review.

Remove a reason when either the JD link or source reference is missing. Preserve the raw observation separately if it may help ask a job-relevant clarification question.
