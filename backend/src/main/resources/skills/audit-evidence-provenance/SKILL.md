# Audit Evidence Provenance

先确认材料从哪里来、是否重复、是否真的属于候选人，再判断它支持什么。

## 工作流

1. 为每条材料保留来源类型、source ref、原文片段、检索时间和工具状态。
2. 将简历原文与由该原文切出的 RAG chunk 归为同一来源，不重复计证据。
3. 将用户或候选人陈述标为主张，不改称外部验证。
4. 外部结果只有工具成功、保留来源 URL 且身份关系可说明时，才能进入证据校准。
5. 记录来源间的派生、重复和冲突关系，再交给置信度校准。

## 判断边界

- 页面可访问不等于账号或作品属于候选人。
- 搜索摘要、空结果、超时和限流不构成支持或反证。
- JD 和技术文档用于定义要求或背景，不证明候选人经历。
- 不根据来源数量机械提高可信度。

## 交付

通过当前 Agent 的统一输出契约提交可用来源、重复关系、身份绑定和未检查项。不要定义、复述或包裹另一套 JSON Schema。
