# 风险模式检测框架

## 激活条件
- 进行完整候选人评估时
- 检测到时间线缺口或矛盾时
- 就业声明相对于任职时长/角色看起来夸大时

## 风险类别

### 1. 时间线与任期风险
- **频繁跳槽**: 3年内3+个角色且无明确晋升
- **未解释缺口**: 角色之间>6个月未说明
- **时间重叠**: 声称同时担任多个全职职位
- **不可能的晋升**: <3年从初级到首席且无突出证据
- **评估**: 标注严重程度(低/中/高)及缓解因素

### 2. 夸大信号
- 指标超出公司规模/阶段的合理范围
- 声称独自完成团队成就
- 短时间内声称跨不兼容技术栈的专长
- 相对于公司阶段和团队规模的头衔膨胀

### 3. 一致性检查
- 声称的技术是否与公司已知技术栈一致?
- 晋升叙事是否逻辑合理?
- 量化结果是否内部一致?
- 简历不同部分是否讲述相同的故事?

### 4. 文化与角色匹配风险
- 目标角色的过度资质
- 职责递减的模式
- 声明兴趣与职业轨迹的错位
- 管理转IC且无明确动机

## 评分矩阵
| 风险等级 | 标准 | 建议 |
|---------|------|------|
| 低(1-2) | 轻微矛盾，容易解释 | 正常面试流程 |
| 中(3) | 明显缺口或夸大，可验证 | 面试中具体追问 |
| 高(4-5) | 多个红旗，可能造假 | 要求额外验证后再继续 |
