# 证据置信度校准

## 激活条件
- 网络搜索和RAG检索完成证据收集后
- 需要将多个证据源综合为一致评估时
- 生成最终推荐分数前

## 证据层级 (置信度递减)

### Tier 1: 直接证据 (置信度 0.9-1.0)
- 候选人发表的描述该工作的技术博客
- 公开仓库中的已合并PR/提交历史
- 专利申请或学术论文
- 候选人演讲的会议录像或幻灯片

### Tier 2: 佐证证据 (置信度 0.7-0.89)
- 公司技术博客提到该项目(未指名候选人)
- 已验证同事在特定技能上的LinkedIn背书
- 技术选型与公司在职期间已知技术栈匹配
- 相关领域的开源贡献

### Tier 3: 间接证据 (置信度 0.4-0.69)
- 公司已知使用声称的技术
- 角色头衔与声称的职责一致
- 相似规模系统的行业标准指标
- 职业发展轨迹与声称的成长一致

### Tier 4: 未验证声明 (置信度 0.1-0.39)
- 未找到外部证据
- 因公司保密/隐身模式无法验证
- 提供的指标无任何佐证
- 自报成就无第三方验证

## 校准规则
1. **没有Tier 1或2证据，永远不分配>0.8置信度**
2. **多个Tier 3信号可提升至等效Tier 2**
3. **矛盾证据立即降低置信度0.3**
4. **缺少证据不等于证伪** — 标注为"不可验证"而非"虚假"
5. **公司声誉调整基线**: 大厂声明因招聘门槛获得轻微提升
